# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organize, search, and delete notes. Notes can be assigned to Personal, Work, or Study categories, and they are saved in the browser using localStorage so they remain available after the page is closed and reopened.

## Features

- Add notes with Personal, Work, or Study categories
- Display notes with readable date and time
- Search notes instantly
- Delete individual notes
- Clear all notes with confirmation
- Validate empty notes
- Limit notes to 200 characters
- Display the correct number of notes
- Save notes using localStorage
- Restore saved notes when the application opens
- Responsive layout for smaller screens
- Category-specific note card styling

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.

You can also use the Live Server extension in Visual Studio Code to run the application locally.
